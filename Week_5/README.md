# Week 5 – Text Generation using RNN, LSTM & GRU

## 📌 Overview

This project was completed as part of the **Celebal Technologies Data Science Internship – Week 5**.

The objective was to understand sequence modeling by implementing Recurrent Neural Networks (RNN), Long Short-Term Memory (LSTM), and Gated Recurrent Units (GRU) for text generation.

A custom **Interstellar-inspired corpus** was used to demonstrate how neural networks learn language patterns and generate meaningful text.

---

## 🎯 Objectives

- Understand sequence modeling using RNNs
- Implement Simple RNN, LSTM, and GRU architectures
- Generate text from a custom corpus
- Compare different recurrent neural network models
- Explore the effects of embedding dimensions, hidden units, and training epochs
