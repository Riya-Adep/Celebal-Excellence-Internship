# Week 8 Assignment – Intelligent Query Routing Agent

This repository contains my **Week 8 assignment** completed as part of the **Celebal Technologies Data Science Internship**.

## 📌 Project Overview

The objective of this assignment was to build an **Intelligent Query Routing Agent** capable of analyzing a user's query, identifying its intent, and routing it to the appropriate processing tool.

The agent demonstrates a simple rule-based approach to AI task routing, where different types of queries are handled by specialized modules.

---

## 🚀 Features

- 🧮 Mathematical expression evaluation
- 🔑 Keyword extraction from text
- 💬 General conversational response handling
- 🧠 Rule-based intelligent query routing
- 📄 Structured JSON responses
- ⌨ Interactive command-line interface

1. Import required libraries

3. Build a Keyword Extraction Tool
4. Test individual tools
5. Develop the Intelligent Query Routing Agent
6. Validate the routing logic with different query types
7. Create an interactive query interface
8. Evaluate the overall system

---

## ⚙ How It Works

The Intelligent Query Routing Agent processes user input and performs the following:

- Detects mathematical expressions and routes them to the Calculator Tool.
- Detects requests for keyword extraction and routes them to the Keyword Extraction Tool.
- Routes general conversational queries to a default response handler.
- Returns results in a structured JSON format.
